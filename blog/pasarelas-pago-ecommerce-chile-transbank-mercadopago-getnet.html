Pasarelas de pago que mejor funcionan en Chile para e-commerce (Transbank vs Mercado Pago vs Getnet)

Elegir pasarela no es solo “cuál es más barata”: importa onboarding, contracargos, UX móvil y cómo se integra con tu stack. Esta guía ordena la decisión con definición, pros/contras, ejemplos y errores comunes.

Introducción

Si vendes online en Chile, la pasarela define cuántos checkouts se completan. Aquí un marco práctico —no una tabla de comisiones que cambia cada trimestre— para decidir con criterio técnico entre Transbank, Mercado Pago, Getnet y otras adquirentes.

¿Qué es?

Una pasarela de pago es el software que conecta tu tienda con redes de tarjetas y medios locales: autentica al comprador, confirma el cobro y te notifica el resultado (aprobado, rechazado, pendiente). No es lo mismo que el banco emisor, ni que tu catálogo: es la capa de checkout.

¿Cuándo usarlo?

  • Cuando pasas de vender solo por Instagram/WhatsApp a un canal propio
  • Cuando necesitas débito/crédito/cuotas de forma recurrente
  • Cuando Ads te trae tráfico y el checkout actual abandona en móvil
  • Cuando requieres webhooks confiables para stock, facturación o despacho
  • Cuando planeas cambiar de proveedor sin reescribir toda la tienda

Ventajas

  • Checkout estandarizado y medible (conversión, rechazos, contracargos)
  • Medios locales que el comprador chileno ya reconoce
  • Integración con tiendas custom, Shopify u otros stacks
  • Base para liquidaciones y conciliación contable
  • Con abstracción correcta, puedes cambiar de proveedor más adelante

Desventajas

  • Onboarding y cumplimiento pueden demorar (giro, documentación)
  • Comisiones y liquidaciones varían y cambian con el tiempo
  • Dependencia de un SDK mal abstraído atrapa tu código
  • Soporte desigual cuando el checkout falla en producción
  • UX de redirección vs embebido impacta conversión móvil

Ejemplos

Transbank

Referente histórico en Chile. Opción fuerte cuando el negocio necesita percepción de “banco tradicional” y un flujo ampliamente reconocido. Planifica integración y onboarding con tiempo.

Mercado Pago

Muy usado por pymes y e-commerce cercanos al ecosistema Mercado Libre. Onboarding a menudo más ágil para validar ventas rápido. Revisa comisiones, liquidaciones y dependencia de marca.

Getnet (y otras adquirentes)

Entran fuerte en retail y omnichannel. Evalúa documentación API, sandbox y soporte cuando falle el checkout en producción: el costo real aparece en los bordes.

Código

Patrón recomendado: no acoples stock y pedidos al SDK de una sola pasarela. Recibe el webhook, valida la firma/estado y actualiza tu dominio interno:

Pseudocódigo webhook

// POST /api/payments/webhook
export async function handleWebhook(req) {
  const event = verifySignature(req); // proveedor A o B
  if (event.status !== 'paid') return { ok: true };

  await orders.markPaid(event.orderId, {
    provider: event.provider,
    transactionId: event.id,
    paidAt: event.paidAt,
  });

  await inventory.reserve(event.orderId);
  return { ok: true };
}

Errores comunes

  • Elegir solo por comisión sin mirar onboarding ni UX móvil
  • Acoplar la lógica de pedidos al SDK de un único proveedor
  • No probar contracargos, rechazos y webhooks duplicados
  • Lanzar Ads antes de que el checkout sea estable en celular
  • Ignorar tiempos de liquidación y flujo de caja

Buenas prácticas

  • Evalúa alta, medios, UX móvil, webhooks, contracargos y soporte
  • Diseña una capa propia de confirmación de pago
  • Prueba sandbox con casos de rechazo y timeout
  • Mide conversión de checkout por dispositivo
  • Documenta el handoff contable (liquidaciones, boletas/facturas)

Preguntas frecuentes

¿Cuál es la mejor pasarela en Chile?

No hay una única. Transbank suele pesar por confianza local; Mercado Pago por agilidad en pymes; Getnet y otras por retail/omnichannel. La mejor es la que calza con tu giro, onboarding y stack.

¿Puedo cambiar de pasarela después?

Sí, si no acoplaste pedidos y stock al SDK. Usa webhooks propios y un estado de orden independiente del proveedor.

¿Shopify o tienda a medida cambia la decisión?

Sí. En Shopify prioriza apps/conectores maduros. En a medida prioriza API, sandbox y control del flujo de confirmación.

¿Las comisiones son el criterio principal?

No. Un 0,5% menos no compensa un onboarding eterno o un checkout que abandona en móvil.

Conclusión

Elige pasarela como decisión de producto: confianza del comprador, velocidad de alta, UX móvil y arquitectura para no quedar atrapado. Las comisiones importan; la conversión y la operación importan más.
